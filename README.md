# Larsen Lights E-Commerce

A modern E-Commerce web application built using ASP.NET Core and nopCommerce architecture.

## Features

- User Authentication & Authorization
- Product Management
- Shopping Cart
- Order Management
- Admin Dashboard
- Responsive UI
- Category & Brand Management
- Secure Payment Integration
- SQL Server Database

## Tech Stack

### Backend
- ASP.NET Core
- C#
- Entity Framework Core
- SQL Server

### Frontend
- HTML
- CSS
- JavaScript
- Razor Views
